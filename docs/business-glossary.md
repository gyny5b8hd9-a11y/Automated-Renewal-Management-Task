# 业务口径与字段定义

> 本文档定义续费意向盘分析中的业务术语、字段公式和统计口径。
>
> 版本：v4.3 | 更新：2026-06-10

---

## 一、核心业务术语

| 术语 | 英文 | 定义 |
|------|------|------|
| LP | Learning Planner | 学习规划师，负责学员全生命周期服务，含续费转化 |
| 意向盘 | Intention Pool | 所有处于续费决策周期的学员集合 |
| 池子 | Pool | 按续费紧迫度划分的学员分组 |
| 续费 | Renewal | 学员在课包消耗完后继续购买新级别课程 |
| 升舱 | Upgrade | 学员在课包未消耗完时提前购买更高级别（价格通常更优） |
| 签单 | Signed | 在本月内完成续费购买的学员 |
| 意向等级 | Intention Level | HIGH/MEDIUM/LOW/RISK 四类分类 |
| 信号 | Signal | 对话中体现的续费意向线索 |

## 二、池子（Pool）分类与映射

| 池子原始名 | 映射名 | 说明 |
|-----------|--------|------|
| 早鸟 | 早鸟 | 课包剩余较多但可提前续费的学员 |
| 当月结课未续 | 当月结课 | 当前月份课包将消耗完的学员 |
| 次月结课未续 | 次月结课 | 下月课包将消耗完的学员 |
| 次次月结课未续 | 次次月结课 | 下下月课包将消耗完的学员 |
| 升舱未续 | 升舱 | 可提前升舱的学员 |
| 活跃低课时未续 | 活跃低课时 | 课时剩余少但近期有上课的学员 |

> **核心池**：以上 6 个池子的并集，是分析和运营的主要范围。

## 三、学员状态分类

| 状态 | 说明 | 分析归属 |
|------|------|---------|
| 执行中 | 正常学习中的学员 | 核心池 |
| 停课 | 已暂停但未退费的学员 | 核心池 |
| 等班 | 等待新班开课的学员 | 核心池 |
| 退费 | 已申请/已办理退费学员 | 非核心 |
| 结课 | 已完成全部课时学员 | 非核心 |

## 四、意向等级定义（方案E）

### 4.1 信号分类上限

| 信号类别 | 每类权重 | 上限 |
|---------|---------|------|
| 高意向信号 | +1 / 类 | 8 分 |
| 中意向信号 | +0.5 / 类 | 6 分 |
| 风险信号 | -1 / 类 | -4 分 |

### 4.2 等级阈值

| 综合得分 | 等级 | 代码 |
|---------|------|------|
| ≥ 3 | 高意向 | HIGH |
| 1.5 ~ 2.99 | 中意向 | MEDIUM |
| -0.99 ~ 1.49 | 观望 | LOW |
| ≤ -1 | 风险 | RISK |

### 4.3 特殊规则

1. **已退款 = 直接风险**：无论其他信号如何
2. **价格敏感 ≠ 风险**：比价/算账说明在做购买决策
3. **价格敏感 + 明确表达"太贵不续"**：降级为风险
4. **课时 ≤ 5 + 无回复**：从观望自动升级为风险

## 五、过程分析表字段定义（v4）

### 5.1 字段公式

| 字段 | 公式 | 分母 |
|------|------|------|
| 学员 | count(学员状态 in [执行中, 停课, 等班]) | — |
| 签单率 | 已签核心池 / 学员 × 100% | 学员 |
| 未续 | 学员 - 已签 | — |
| 覆盖率 | 有执行动作核心池 / 学员 × 100% | 学员 |
| H% | 高意向核心池 / 学员 × 100% | 学员 |
| M% | 中意向核心池 / 学员 × 100% | 学员 |
| L% | 观望核心池 / 学员 × 100% | 学员 |
| R% | 风险核心池 / 学员 × 100% | 学员 |
| >7天 | 最后沟通>7天核心池 / 学员 × 100% | 学员 |
| 断联率 | 覆盖过但>7天未联系 / 有执行动作人数 × 100% | 有执行动作人数 |
| 退费占比 | 退费人数 / 总人数 × 100% | 总人数 |
| 结课占比 | 结课人数 / 总人数 × 100% | 总人数 |

### 5.2 字段分组

| 分组 | 包含字段 | 分母 |
|------|---------|------|
| 核心池展开 (左10列) | 学员 / 签单率 / 未续 / 覆盖率 / H% / M% / L% / R% / >7天 / 断联率 | 核心池人数 |
| 非核心占比 (右2列) | 退费占比 / 结课占比 | 总人数 |

### 5.3 着色规则

| 条件 | 颜色 |
|------|------|
| 覆盖率 < 25% | 红色 |
| >7天 > 30% | 红色 |
| >7天 > 20% | 黄色 |
| 断联率 ≥ 50% | 红色 |
| 断联率 ≥ 30% | 黄色 |

## 六、低意向原因分类（4类互斥）

| 原因代码 | 分类 | 判定逻辑 |
|---------|------|---------|
| NO_INTERACTION | 无互动 | LP发送多条消息但客户从未回复 |
| PURE_WAIT | 纯观望 | 客户有极简回复但无实质内容，无正面或负面表达 |
| LOW_INTENT | 意愿不足 | 客户明确表达不续/已报其他/没时间等，属风险信号主导 |
| NEGATIVE_DRAG | 负面拉低 | 投诉/不满/退费等负面信号累计拉低综合得分 |

---

## 七、LP 销售问题分类（7类）

| 问题类型 | 判定标准 |
|---------|---------|
| 模板轰炸 | 连续3条以上消息高度相似，无差异化内容 |
| 打卡干扰 | 打卡/活动类消息占比 > 50%，续费话题被稀释 |
| 单向广播 | 客户从未回应任何消息，LP 持续发送 |
| 过早放弃 | 2次跟进无回应后停止，距结课尚有30天+ |
| 转介绍主导 | 转介绍话题占比 > 续费话题 |
| 缺少退费保障 | 续费谈话中未提及退费保障 |
| 缺少价格锚点 | 续费谈话中未进行价格对比/价值说明 |

## 八、信号分类体系

### 8.1 高意向信号（4类）

| 类别 | 权重 | 典型关键词 |
|------|------|-----------|
| 主动询价 | +3 | "续费多少钱""现在什么价格""课包怎么买" |
| 价格敏感 | +3 | "对比了一下""一节课平均多少""算下来每个月" |
| 学习规划 | +2 | "下个级别学什么""学完要多久""还剩多少课" |
| 决策推进 | +2 | "怎么付款""买了什么时候开始""会续的" |

### 8.2 中意向信号（2类）

| 类别 | 权重 | 典型关键词 |
|------|------|-----------|
| 积极回应 | +1 | "好的我知道了""谢谢提醒""孩子确实进步了" |
| 犹豫考量 | +1 | "跟爸爸商量一下""我再想想""等用完再说" |

### 8.3 风险信号（4类）

| 类别 | 权重 | 典型关键词 |
|------|------|-----------|
| 明确不续 | -4 | "不续了""不学了""不买了""报了别的班" |
| 投诉不满 | -3 | "老师不行""APP总出问题""你们服务太差了" |
| 退款倾向 | -4 | "怎么退款""能退多少""我要退款" |
| 长期失联 | -2 | 30天+无任何回复，所有渠道触达失败 |
