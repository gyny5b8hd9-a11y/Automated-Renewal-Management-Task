# 续费意向盘飞书三报表逻辑完整说明

> 适用版本：v4.3 | 更新日期：2026-06-11

---

## 一、飞书三 Sheet 全貌

三个 Sheet 分别对应三种角色和三种核心提问：

| Sheet | 谁看 | 回答什么问题 |
|-------|------|------------|
| Sheet1 续费意向盘 | LP 个人 | "我的学员谁该优先跟进？" |
| Sheet2 续费过程分析 | 小组长/管理者 | "各组的续费推进健康度如何？" |
| Sheet3 低意向原因分析 | 策略/培训岗 | "为什么这么多人低意向？根因在哪？" |

三者共享同一份原始数据源（SmartBI 导出的学员对话明细），但分别从三个维度独立计算——Sheet1 是原子数据，Sheet2 和 Sheet3 各自从原始对话直接聚合，确保口径一致、可单独追溯。

## 二、Sheet1：续费意向盘（21列明细）

### 2.1 定位

最底层的数据层。**每一行 = 一个学员**，每一列 = 一个分析维度。LP 打开后按自己的名字筛选，即可看到名下所有学员的续费状态全景。

### 2.2 字段分组拆解

21 列按数据来源分为四组：

#### 第一组：身份维度（4列）— 来自 SmartBI 原始数据

| 序号 | 字段 | 数据来源 | 说明 |
|------|------|----------|------|
| 1 | 序号 | 生成 | 流水号，从 1 开始 |
| 2 | 学员ID | SmartBI 导出 | 学员唯一标识 |
| 3 | 归属LP | SmartBI 导出 | 该学员对应的学习规划师 |
| 4 | 小组 | 映射计算 | 从 LP 姓名反查所属业务小组 |

#### 第二组：业务维度（4列）— 来自 SmartBI 原始数据

| 序号 | 字段 | 数据来源 | 说明 |
|------|------|----------|------|
| 5 | 区域 | SmartBI 导出 | 港澳 / 美澳 |
| 6 | 池子 | SmartBI 导出 | 早鸟 / 当月结课 / 次月结课 / 次次月结课 / 升舱 / 活跃低课时 |
| 7 | 续费金额 | SmartBI 导出 | 预期续费金额（元） |
| 8 | 语种 | SmartBI 导出 | 学员所学语种 |

#### 第三组：信号分析维度（9列）— 来自 analyze_renewal.py 方案E计算

这是 Sheet1 的核心产出，由评分引擎从对话文本中自动提取：

```
原始对话 "材料全对话"
   → 33类关键词匹配（4类高意向 + 2类中意向 + 4类风险）
   → 方案E分类上限法评分
   → 生成以下9列
```

| 序号 | 字段 | 计算逻辑 |
|------|------|----------|
| 9 | 失联天数 | 今天日期 - 最后一次沟通日期 |
| 10 | 近7天动作数 | 最近7天内 LP 对该学员的跟进动作次数 |
| 11 | 是否失联超过7天 | 失联天数 > 7 → "是"；否则 "否" |
| 12 | 意向等级 | HIGH(≥3) / MEDIUM(≥1.5) / LOW(默认) / RISK(≤-1) |
| 13 | 综合得分 | SUM(高意向类分,上限8) + SUM(中意向类分,上限6) + SUM(风险类分,下限-4) |
| 14 | 正向信号数 | 匹配到的高意向+中意向信号类别总数 |
| 15 | 风险信号数 | 匹配到的风险信号类别总数 |
| 16 | 总消息数 | LP + 客户在对话中的总消息条数 |
| 17 | 正向信号 | 具体匹配到的高/中意向信号名称列表（如：主动询价、比价、明确表态续费） |
| 18 | 风险信号 | 具体匹配到的风险信号名称列表（如：明确不续、询问退款、投诉老师） |
| 19 | 最近消息摘要 | 对话中最后一条含实质性内容的客户消息截取 |
| 20 | 跟进行动建议 | 根据意向等级自动生成：高→"48h内推动成交"；中→"3天内深度培育"；观望→"保持常规触达"；风险→"主管介入" |

> **注意**：失联超过7天（第11列）≠ 断联。断联 = 有执行动作但超过7天未联系，分母为有执行动作人数，计算公式不同，详见 Sheet2。

#### 方案E 评分模型速查

| 信号类别 | 每类权重 | 上限 | 典型关键词 |
|---------|---------|------|-----------|
| 主动询价 | +3 | — | "续费多少钱""现在什么价格""课包怎么买" |
| 价格敏感 | +3 | — | "对比了一下""一节课平均多少" |
| 学习规划 | +2 | — | "下个级别学什么""学完要多久" |
| 决策推进 | +2 | — | "怎么付款""会续的" |
| 积极回应 | +1 | — | "好的我知道了""孩子确实进步了" |
| 犹豫考量 | +1 | — | "跟爸爸商量""再想想" |
| 明确不续 | -4 | — | "不续了""报了别的班" |
| 投诉不满 | -3 | — | "老师不行""APP总出问题" |
| 退款倾向 | -4 | — | "怎么退款""能退多少""我要退款" |
| 长期失联 | -2 | — | 30天+无任何回复 |

**特殊规则：**

- 已退款 = 直接风险（无视其他信号）
- 价格敏感 ≠ 风险（算账说明在做购买决策）
- 价格敏感 + 明确表达"太贵了不续" → 降级为风险
- 课时 ≤ 5 + 无任何回复 → 自动从观望升级为风险

| 综合得分 | 意向等级 |
|---------|---------|
| ≥ 3 | 🔥 高意向 HIGH |
| 1.5 ~ 2.99 | 🟡 中意向 MEDIUM |
| -0.99 ~ 1.49 | 🔵 观望 LOW |
| ≤ -1 | 🔴 风险 RISK |

### 2.3 LP 使用方式

```
打开 Sheet1 → 筛选自己的名字 → 按"意向等级"排序
  ↓
步骤1：先看🔥高意向 → 48h 关单窗口，直接发方案+退费保障+活动紧迫感
步骤2：再看🔴风险 → 停止模板消息，需主管48h内介入
步骤3：扫一眼🔵观望 → 检查失联天数是否异常
```

## 三、Sheet2：续费过程分析（14列交叉表）

### 3.1 定位

管理视角的汇总表，从"单兵作战"上升到"团队健康度"。

- **行 = 小组**（8个：港澳1/2/3组 + 美澳1/2/3/4/5组）
- **列 = 池子**（6个池子：早鸟 / 当月结课 / 次月结课 / 次次月结课 / 升舱 / 活跃低课时）
- **交叉格 = 14个指标**，反映该小组在该池子的续费推进健康度

### 3.2 两行表头结构

```
第一行：团队 | 池子 | ←──────────── 核心池指标（11列） ────────────→ | 退费占比 | 结课占比
第二行：      |       | 学员 | 签单率 | 未续 | 覆盖率 | H% | M% | L% | R% | >7天 | 断联率 |        |
```

### 3.3 核心池 vs 非核心：两大分母

| 分组 | 分母 | 包含列 | 含义 |
|------|------|--------|------|
| 核心池指标 | 核心池人数 = 执行中 + 停课 + 等班 | 学员 / 签单率 / 未续 / 覆盖率 / H% / M% / L% / R% / >7天 / 断联率 | 正在跟的学员，有推进续费的意义 |
| 非核心占比 | 总人数 = 核心池 + 退费 + 结课 | 退费占比 / 结课占比 | 反映池子整体"损耗率" |

**设计意图：** 执行中的学员才有推进续费的价值；退了费的学员自然不在推进范围内。但退费/结课占比放在右侧作为"池子健康度"的参考视角。

### 3.4 14列逐列拆解

#### 核心池展开（11列）

| 序号 | 列名 | 计算公式 | 分母 | 业务解读 |
|------|------|----------|------|----------|
| 1 | 学员 | `count(学员状态 in [执行中,停课,等班])` | — | 这个小组×池子有多少人在跟 |
| 2 | 签单率 | `已签 / 学员 × 100%` | 学员 | 本月已成交占比，直接反映转化效率 |
| 3 | 未续 | `学员 - 已签` | — | 还有多少人没签（绝对值，便于分配资源） |
| 4 | 覆盖率 | `有执行动作人数 / 学员 × 100%` | 学员 | LP 是否在做跟进动作；< 25% 红色预警 |
| 5 | H% | `高意向人数 / 学员 × 100%` | 学员 | 高意向学员占核心池比例 |
| 6 | M% | `中意向人数 / 学员 × 100%` | 学员 | 待培育学员占核心池比例 |
| 7 | L% | `观望人数 / 学员 × 100%` | 学员 | 被动/沉默学员占核心池比例 |
| 8 | R% | `风险人数 / 学员 × 100%` | 学员 | 有流失风险的学员比例 |
| 9 | \>7天 | `最后沟通>7天人数 / 学员 × 100%` | 学员 | 一周以上没人联系的比例 |
| 10 | 断联率 | `有动作但>7天未联系 / 有执行动作人数 × 100%` | 有执行动作人数 | 跟了一半跟丢了的比例 |
| 11 | — | — | — | — |

#### 断联率 vs >7天：关键区别

| 指标 | 分母 | 衡量什么 |
|------|------|---------|
| >7天 | 全体核心池学员 | "冰冷"程度 —— 多少人超过一周没人管 |
| 断联率 | 有执行动作的学员 | "半途而废"程度 —— 跟了一阵就断了 |

一个 LP 可能覆盖率很高（都在跟），但断联率也高（跟了一半都断了），说明执行力有问题——这比单纯的">7天占比高"更需要重视。

#### 非核心占比（2列）

| 列名 | 计算公式 | 分母 | 业务解读 |
|------|----------|------|----------|
| 退费占比 | `退费人数 / 总人数 × 100%` | 总人数 | 这个池子已退款的比例 |
| 结课占比 | `结课人数 / 总人数 × 100%` | 总人数 | 正常结课自然流失的比例 |

### 3.5 着色预警规则

| 条件 | 颜色 | 含义 | 需要做什么 |
|------|------|------|-----------|
| 覆盖率 < 25% | 🔴 红色 | LP 几乎没在跟，严重执行问题 | 立即督促该组 LP 开展跟进 |
| \>7天 > 30% | 🔴 红色 | 超过三成人一周没人联系 | 排查是否为人力不足或分配不合理 |
| \>7天 > 20% | 🟡 黄色 | 需关注但尚未严重 | 提醒组长 |
| 断联率 ≥ 50% | 🔴 红色 | 跟了一半以上就断了 | LP 执行力问题，需培训或换人 |
| 断联率 ≥ 30% | 🟡 黄色 | 需关注 | 提醒组长跟踪 |

### 3.6 管理者使用方式

```
打开 Sheet2 → 先扫全局着色
  ↓
红色格子最多的组 → 优先处理
  ↓
覆盖率红 → 检查该组人力分配 / LP 是否在岗
>7天红 → 检查该组学员数是否超出 LP 承载能力
断联率红 → 检查该组 LP 的跟进技能和工具使用
  ↓
横向对比：看各组的签单率排名，找标杆 → 推广
```

## 四、Sheet3：低意向原因分析（11列归因表）

### 4.1 定位

当 Sheet2 中某个组 L% 偏高时，管理者自然会问："**为什么这个组这么多人低意向？**"

Sheet3 回答这个问题。它把所有标记为 LOW（观望）和 RISK（风险）的学员拿出来，逐一归因到 4 类原因之一。

### 4.2 四类互斥原因

| 代码 | 分类 | 判定逻辑 | 典型场景 |
|------|------|----------|----------|
| NO_INTERACTION | 无互动 | LP 发了多条消息，学员从未回复过任何一条 | 家长已卸载APP / 更换微信号 / 完全失联 |
| PURE_WAIT | 纯观望 | 学员有极简回复（嗯/好/ok），但无正面或负面实质表达 | 家长看到消息但不想回应 |
| LOW_INTENT | 意愿不足 | 学员明确表达不续/已报其他班/没时间/太贵等 | "不续了""报了别的班""没时间" |
| NEGATIVE_DRAG | 负面拉低 | 投诉老师/APP、不满服务、要求退款等负面信号拉低得分 | "老师不专业""APP总卡""我要退款" |

### 4.3 互斥优先级

一个学员只归入一类，优先级从高到低为：

```
无互动 > 意愿不足 > 负面拉低 > 纯观望
```

- 如果学员从未回复 → 无互动（即使对话中含其他信号也无意义）
- 如果有明确不续表达 → 意愿不足（即使也投诉过，但"不续"是更根本的原因）
- 如果只有投诉/负面，没有拒绝 → 负面拉低
- 完全没有上述特征 → 纯观望

### 4.4 输出结构

```
行 = 区域 × 小组（港澳/美澳 × 各小组）
列 = 4类原因 + 各类占比 + 总人数
```

| 列名 | 说明 |
|------|------|
| 区域 | 港澳 / 美澳 |
| 小组 | 具体小组名称 |
| 无互动人数 | 从未回复的学员绝对数 |
| 无互动占比 | 无互动 / 低意向总人数 × 100% |
| 纯观望人数 | 有回复但无实质内容的学员数 |
| 纯观望占比 | 纯观望 / 低意向总人数 × 100% |
| 意愿不足人数 | 明确拒绝/已有替代方案的学员数 |
| 意愿不足占比 | 意愿不足 / 低意向总人数 × 100% |
| 负面拉低人数 | 投诉/不满拉低得分的学员数 |
| 负面拉低占比 | 负面拉低 / 低意向总人数 × 100% |
| 低意向总人数 | 该组低意向+风险学员总数 |

### 4.5 策略对照表

| 如果看到... | 根因推断 | 对应策略 |
|------------|---------|---------|
| 无互动占比高 | LP 触达有问题，消息频率不够或渠道不对 | 培训方向：提升触达频次 + 多渠道路径（语音/短信/APP推送） |
| 纯观望占比高 | 学员在比价或等待更优时间窗口 | 策略：加强价格锚点 + 涨价紧迫感 + 学习规划衔接 |
| 意愿不足占比高 | 产品价值感不足或竞品冲击 | 需产品/市场侧介入：课程升级 + 竞品分析 + 优先转介绍引导 |
| 负面拉低占比高 | 服务质量问题 | 需主管介入：1v1 问题解决 + 更换 LP + 补偿方案 |

### 4.6 策略/培训岗使用方式

```
打开 Sheet3 → 按小组扫4类占比
  ↓
港澳1组意愿不足最高 → 了解是否该组学员集中接触了竞品
美澳3组无互动最高 → 检查时区差异是否影响 LP 触达时效
港澳2组负面拉低最高 → 排查该组是否有大量投诉事件
  ↓
制定差异化策略 → 分配到培训/主管/产品侧落地
```

## 六、附录：关键术语速查

| 术语 | 定义 |
|------|------|
| LP | Learning Planner，学习规划师 |
| 池子 | 按续费紧迫度划分的学员分组（共6个） |
| 核心池 | 执行中 + 停课 + 等班，即有续费推进意义的学员 |
| 签单率 | 本月已续费 / 核心池学员 × 100% |
| 覆盖率 | LP 有执行跟进动作的学员 / 核心池 × 100% |
| 断联率 | 有跟进动作但超过7天未联系 / 有跟进动作的学员 × 100% |
| 方案E | 分类上限法评分，当前使用的评分模型 |
| 信号 | 对话文本中体现续费意向的语义线索 |
