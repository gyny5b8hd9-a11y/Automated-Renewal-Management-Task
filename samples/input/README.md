# 输入样例说明

## renewal_chat_sample.xlsx

包含 10 条脱敏样例学员对话数据，用于验证工具能否正常跑通。

### Sheet1: 学员对话数据

| 字段 | 类型 | 说明 |
|------|------|------|
| 学员ID | string | 虚构学员标识 (STU-20260001 ~ STU-20260010) |
| 学员姓名 | string | 已脱敏为 `学员X***` |
| LP | string | 已脱敏为 `LP-X***` |
| 池子 | string | 覆盖 6 种池子类型 |
| 小组 | string | 覆盖港澳/美澳多组 |
| 区域 | string | 港澳 / 美澳 |
| 沟通时间 | date | 2026-06-01 ~ 2026-06-06 |
| 材料全对话 | string | 虚构 LP-家长对话，含多种信号类型 |

### Sheet2: 字段说明

输入数据各字段的详细说明和示例值。

### 样例覆盖的信号类型

| 学员 | 预期等级 | 信号特征 |
|------|---------|---------|
| STU-20260001 | 高意向 | 主动询价 + 比价 + 明确表态续费 |
| STU-20260002 | 中意向 | 积极回应但未下决心 |
| STU-20260003 | 观望 | 敷衍回应、被动接收 |
| STU-20260004 | 风险 | 直接询问退款 |
| STU-20260005 | 风险 | 明确拒绝续费 |
| STU-20260006 | 观望 | 长期失联、无回应 |
| STU-20260007 | 高意向 | 学习规划 + 比价 |
| STU-20260008 | 风险 | 课程不满 + 投诉 |
| STU-20260009 | 高意向 | 主动询价 + 决策推进 |
| STU-20260010 | 风险 | 投诉 + 明确退款 |

### 注意事项

- **所有数据均为虚构，不含任何真实学员/家长信息**
- 对话样本中涉及的价格/折扣已替换为 `XXXX` 占位符
- LP 姓名已匿名化处理
- 仅供功能验证使用，不影响线上分析
